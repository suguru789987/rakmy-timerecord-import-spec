# エクセル版（配布用）

**TSVから生成した派生物です。** 内容の正本はリポジトリ直下の `.tsv` と `.md` です。

## 生成方法

```
python3 build_excel.py
```

TSVを変更したら再生成してください。**エクセルを直接編集しても TSV には反映されません。**

## ファイル

| | 内容 | 記入する列 |
|---|---|---|
| `01_受け入れ条件_使い方.xlsx` | 定義表と確認表の使い方 | — |
| `02_受け入れ条件_定義表.xlsx` | 何を守るか・なぜか | — |
| `03_受け入れ条件_確認表.xlsx` | 実装が条件に合致しているかの判定 | 実装状況・検証結果・判定 |
| `04_検証プラン_操作系.xlsx` | 画面を操作する検証 | 実際の結果・判定 |
| `05_検証プラン_計算系.xlsx` | 数値・上限の検証 | 実際の値・判定 |
| `06_検証用データセット.xlsx` | 検証に使うデータ | — |
| `07_実装マイルストーン表.xlsx` | M1〜M6の実装順序 | 実装状況・完了日 |
| `08_トレーサビリティ表.xlsx` | 仕様と条件の対応 | — |
| `09_進捗（確認表つき）.xlsx` | **フロー別・マイルストーン別の自動集計** | 確認表シートに記入 |

## 仕込んであるもの

- **プルダウン**: 実装状況（○△×）／判定（合格・不合格）
- **色分け**: フロー1〜4／MVP必須は赤／合格は緑・不合格は赤
- 見出し行の固定とオートフィルタ
- `09` はフロー別とマイルストーン別の COUNTIFS 集計

## 検証結果の扱い

**エクセルに記入した結果は `progress.py` では集計されません。** `progress.py` はリポジトリの TSV を読みます。

- エクセルで完結させる → `09` の進捗シートで判断する
- リポジトリで管理する → TSV に記入して `python3 progress.py`

どちらか片方に決めてください。
